# Tablón de avisos (módulo de ejemplo)

Referencia viva de [docs/MODULOS.md](../../docs/MODULOS.md). Muestra el patrón completo: manifiesto con ficha de
tratamiento, permisos (`ver`, `publicar`, `moderar`), migración inicial, API con `acceso(...)`, bitácora sin contenido,
`exportar_titular`, `depurar` (365 días) y una página con la cabecera común.

Se registra inactivo y visible solo para administradores. Para probarlo: **Administración › Módulos › Tablón de avisos**,
marcar *Activo* y guardar. No conviene activarlo en producción.
